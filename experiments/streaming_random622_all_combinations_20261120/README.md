# Original Streaming on the random 6:2:2 split

Reproduce original Streaming with independent model/domain detectors on a frozen unconstrained question-family split. Each domain uses its own seeded family shuffle and60/20/20 boundaries, without label, source or recovery stratification. This is an exploratory re-split of historically inspected data.

Step and Prefix use their original fixed exponential pools, feature normalization and distinct original optimization recipes. All native candidate layers are evaluated independently on TRAIN: DeepSeek32, Gemma60, Qwen64. Each arm freezes its own complete VAL-selected checkpoint/layer and VAL F1max threshold before selected TEST once. See [the configuration](config_all_models.json) and [accepted results](result/accepted_cells.json).

Answer takes the final retained Prefix score from that frozen Prefix detector, with no Answer layer or checkpoint reselection. Its threshold uses complete Answer VAL when saved predictions are available. Qwen Logic and Factuality Answer provide independently verified AUROC, AP and TPR@1%FPR only; their complete saved Prefix VAL predictions are unavailable locally, so thresholds and ACC/F1 remain unavailable.

Compatible label-independent pool components are reused by exact identity. Missing DeepSeek components use a separately versioned native source after explicit approval, native hidden-state, causal, pooling and independent CPU checks. Historical missing components did not reproduce their old byte hashes; those failures remain preserved. The new source hashes do not claim historical byte identity. Data, labels, split, model precision and detector training parameters are unchanged. Source version and approval hashes accompany accepted results.

All reported predictions pass independent CPU checks of IDs, labels, coverage, selection, thresholds and metrics; no independent detector replay is claimed. Gemma Science had identical same-layer parameter artifacts, resolved by byte identity before TEST rather than by preferring an earlier update. Unfinished results are empty in [the comparison](../../reports/main_result/comparison_random_split_candidate.md). No data, feature banks, predictions or weights are published.
