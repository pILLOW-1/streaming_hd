# Research trajectory

This directory records research decisions and implementation provenance in English. It contains no credentials, internal service messages, full conversation dumps or unpublished theory.

- [DECISIONS.md](DECISIONS.md): current scientific and repository decisions.
- [TIMELINE.md](TIMELINE.md): development milestones and open implementation questions.
- [source_manifest.json](source_manifest.json): original relative source paths and SHA-256 identities before portability edits.

Record future experiments with a unique ID, configuration/data/code identities, selection rule, results and limitations. Add an entry here when a scientific decision changes. Failed and abandoned work should remain identifiable; a synthetic check is not evidence of benchmark quality.
